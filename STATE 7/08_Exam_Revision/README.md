# Unit 7 Exam Revision

## 7.1 ORM
ORM maps objects to relational tables. Know entity, mapping, persistence context, relationships, lazy/eager loading, transactions and JPA vs Hibernate.

## 7.2 Hibernate
Know `SessionFactory`, `Session`, transaction, entity lifecycle, HQL, annotations and configuration.

## 7.3 Web Framework
Know HTTP, MVC, controller, model, view, routing, REST, request/response lifecycle and servlet concepts.

## 7.4 Spring Boot
Know IoC, DI, beans, `@SpringBootApplication`, controllers, services, repositories, starters, auto-configuration and external configuration.

## 7.5 Concurrency
Know thread lifecycle, Runnable/Callable, synchronization, race conditions, volatile, atomic classes, locks, executors, Future, deadlock and thread safety.

## 7.6 Patterns
Singleton = one logical instance.
Factory = object creation abstraction.
Abstract Factory = related object families.

## High-value comparisons
- JDBC vs ORM
- JPA vs Hibernate
- Spring MVC vs Spring Boot
- Thread vs process
- synchronized vs AtomicInteger
- Factory vs Abstract Factory
- lazy vs eager loading
