# Distributed Tecnoloy - Java Notes and Implementations

This folder contains topic-wise Java files for:

1. TCP, UDP, IP Address and Ports
2. Socket Programming using TCP and UDP
3. Working with URLs and URLConnection
4. Email Handling using Java Mail API
5. Architecture of RMI
6. Creating and Executing RMI Applications
7. Architecture of CORBA
8. RMI vs CORBA
9. IDL and a Simple CORBA Program

## Compile and run example

```bash
javac 01_NetworkBasics.java
java NetworkBasics
```

For server-client examples, run server first, then client in another terminal.

For JavaMail examples, add `jakarta.mail` dependency in your project build.
