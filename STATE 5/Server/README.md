# Server - Java SOLID Principles

This folder contains service implementations demonstrating the five SOLID principles of object-oriented design in Java.

## Files

1. **SingleResponsibilityService.java** - SRP: A class should have only one reason to change.
2. **OpenClosedService.java** - OCP: Classes should be open for extension, closed for modification.
3. **LiskovSubstitutionService.java** - LSP: Subtypes must be substitutable for their base types.
4. **InterfaceSegregationService.java** - ISP: Clients should not be forced to depend on interfaces they do not use.
5. **DependencyInversionService.java** - DIP: Depend on abstractions, not concretions.

Each file includes a `main` method for standalone execution.
